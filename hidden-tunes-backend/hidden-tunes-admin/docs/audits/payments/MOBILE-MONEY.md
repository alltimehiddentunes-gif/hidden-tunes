# Mobile Money

## Safe model

Prepaid **30-day** or **365-day Premium pass** — user authorizes each renewal payment.

Do **not** label as auto-renewing subscription unless provider + country + merchant + method all confirm recurring charges.

## UX copy

- 30-day Premium pass
- Annual Premium pass
- Renewable membership / prepaid Premium access

## Ops

Expiry reminders required (push/email) because there is no automatic renewal.

## Status

Design-only; implemented via Flutterwave/Paystack channels in Phase C.
