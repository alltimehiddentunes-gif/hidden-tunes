# Desktop ↔ Mobile Music Parity Map

| Mobile Explore | Desktop Music target | Notes |
|----------------|----------------------|-------|
| Discovery header | Compact `Music` header + search (desktop top bar) | Keep desktop search; drop verbose anti-history subtitle |
| Keep Listening / Recent | Recent rail on Discover **if** local recent exists | Real data only |
| Explore The Catalog carousel | Optional compact featured / New Releases | Max ~240px; remove if weak |
| Stay Awhile (songs) | **Songs** as strongest Discover section | Dense rows, not giant squares |
| Stay Awhile (albums) | Albums rail | 150–190px |
| Creators | Artists rail | Circular 110–150px |
| Genre Spotlights | Genres | Editorial tiles, not album-grid mix |
| Mood First | Moods | Distinct from genres |
| Stations / Rooms | Skip unless desktop already has real rooms | Do not invent |
| (none) Charts / New Releases | Keep if desktop catalog builders already produce them | Real only |
| No Songs tab | Desktop tabs: Discover · Songs · Albums · Artists · Genres · Playlists | Simplify 10-item side nav → horizontal tabs |
| Search route | Global Music search | Already present |

## Product priorities (desktop)
1. Playable Songs first  
2. New / Featured  
3. Recent (if real)  
4. Albums · Artists  
5. Genres · Moods  
6. Charts (if real)  
7. Deep All Songs via Songs tab + load more  

Do **not** copy Home (`music-feed`) personalisation sections onto Music.
