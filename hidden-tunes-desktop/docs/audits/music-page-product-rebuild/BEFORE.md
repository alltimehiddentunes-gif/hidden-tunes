# Music Page Product Rebuild — BEFORE (visual)

**HEAD:** `a59b4cbbb7febcd1f0a9aed8b4459f98ab1f5177`  
**Evidence:** `BEFORE-1024.png` · `BEFORE-1280.png` · `BEFORE-1440.png` · `BEFORE-LARGE.png`

## Plain-language diagnosis

Artwork containment is fixed. The **product page is still unfinished**.

### What dominates
- A tall **Browse sub-nav column** eats centre width before any catalogue.
- Verbose **"Browse the catalog"** copy + a weak **Featured Release** (DEV placeholder "DA").
- Oversized **New Releases** square cards with repetitive empty art.
- Idle **Now Playing** rail still feels as important as Music content.

### What is missing above the fold
| Width | Above fold |
|-------|------------|
| 1024 | Title + Featured only — **no Songs, no Albums rail, no Artists** |
| 1280–1720 | Title + New Releases + start of Charts — **still zero Songs** |

User cannot answer “what can I play now?” without scrolling or opening Songs in the secondary nav.

### Organisation problems
- Songs / Albums / Artists are **buried in a 10-item side menu**, not primary destinations.
- Discover feels like a **catalogue dump of discovery rails**, not a music destination.
- Cards feel random: release cards huge; charts are text blocks; no song rows on Discover.
- Rails inconsistent; desktop width wasted on empty header space.
- Subtitle literally says “not your listening history” — opposite of mobile Explore’s Keep Listening.
- Does **not** resemble mobile Explore (rooms → moods → genres → albums → creators).
- Search is fine (UTF-8 OK); filters feel like an admin sidebar, not integrated tabs.

### Acceptance failure
Technically browsable; **not premium, not song-first, not parity-shaped**.
