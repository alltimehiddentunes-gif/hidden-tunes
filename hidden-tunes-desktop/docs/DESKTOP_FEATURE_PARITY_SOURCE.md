# Desktop 1.0.0 feature parity source

The committed Desktop source is the authority for Home, Music, Search, Artists, Albums, Favorites, Library, Playlists, Radio, Podcasts, Audiobooks, Motivationals, Lectures, TV, Settings, playback ownership, queue controls, player modes, persistence, responsive behavior, and native window controls.

Installed validation proved packaged Search routing into Music, Radio, Podcasts, Audiobooks, TV, Motivationals, and Lectures. Sports is explicitly not included in this release gate. Emotional Worlds backend deployment is deferred; the Desktop client surface may remain present without claiming production backend availability.
